  <action>
Create `src/components/marketing/ComparisonTable.astro` as a pure Astro component (no React island needed -- content is entirely static).

**Section structure** (matching existing marketing section patterns):
- Section wrapper: `<section id="comparison" class="py-16 sm:py-24 bg-gray-50">`
- Container: `<div class="max-w-7xl mx-auto px-4 sm:px-6 lg:px-8">`
- Section header (centered): h2 "Compare Your Options" + subtitle "See how VWCGApp stacks up against traditional approaches"
- Header styling: `text-2xl sm:text-3xl lg:text-4xl font-bold text-gray-900` (matches Features, SampleReport, MiniAssessment)

**Table structure** (semantic HTML, WCAG compliant):
- Wrap table in `<div class="overflow-x-auto -mx-4 px-4 md:mx-0 md:px-0">` for mobile horizontal scroll
- Use `<table>` with `aria-label="Comparison of VWCGApp, consultant services, and DIY approaches"`
- Add `<caption class="sr-only">` describing the table content
- All header cells use `<th scope="col">` or `<th scope="row">`

**Column headers** (4 columns):
1. Empty header cell (feature label column) - `<th scope="col">` with sr-only "Feature" text
2. VWCGApp column header - highlighted with "Recommended" badge
3. Consultant column header
4. DIY/Guessing column header

**VWCGApp column highlighting** (visual hierarchy):
- "Recommended" badge: absolutely positioned pill above VWCGApp header using `absolute -top-3 left-1/2 -translate-x-1/2 bg-indigo-600 text-white text-xs font-semibold px-3 py-1 rounded-full whitespace-nowrap`
  - Use indigo-600 (not primary-500) to match the CTA section and report header color scheme already in use
- VWCGApp column cells: `bg-indigo-50 border-x-2 border-indigo-500` for subtle highlight
- VWCGApp column text: `font-semibold text-indigo-700` for emphasis
- Other columns: standard `text-gray-600`

**Table rows** (5 comparison rows covering all 4 CMP requirements plus 2 bonus differentiators):

Row 1 - Time to Insight (CMP-02):
- VWCGApp: "10 minutes" (with a small clock icon or bold text)
- Consultant: "2-4 weeks"
- DIY: "Never"

Row 2 - Cost (CMP-03):
- VWCGApp: "Free"
- Consultant: "$5,000-$20,000"
- DIY: "$0 (but no insights)"

Row 3 - Objectivity (CMP-04):
- VWCGApp: "AI-based, consistent"
- Consultant: "Varies by consultant"
- DIY: "Biased"

Row 4 - Instant Results (bonus differentiator):
- VWCGApp: Green checkmark + sr-only "Yes"
- Consultant: Red X + sr-only "No"
- DIY: Red X + sr-only "No"

Row 5 - Privacy (bonus differentiator):
- VWCGApp: "100% private, browser-only"
- Consultant: "Shared with consultant"
- DIY: "Varies"

**Icons:** Use inline SVG for Check (green, `text-emerald-500`) and X (red, `text-red-400`) marks rather than importing lucide-react (avoids React hydration for static content). Include `<span class="sr-only">` text for each icon.

**Responsive design:**
- Table has `min-w-[600px] md:min-w-0` to force horizontal scroll on mobile while being full-width on desktop
- Feature label column (first column): `sticky left-0 bg-gray-50 z-10 md:static` on mobile for sticky labels
- On mobile, the sticky first column keeps feature names visible while scrolling through options
- Row backgrounds alternate: even rows get slightly different background for readability

**Styling details:**
- Table: `w-full border-collapse`
- Header row: `border-b-2 border-gray-300`
- Body rows: `border-b border-gray-200`
- Cell padding: `p-4`
- Feature labels (row headers): `font-medium text-gray-900`
- VWCGApp header: `font-bold text-gray-900 text-lg` with relative positioning for badge
- Other column headers: `font-semibold text-gray-700`

Do NOT use any React imports. This is a pure Astro/HTML component.
