  <action>
Create reusable CounterIsland component with viewport-triggered animation and accessibility support.

**Create new file:** `src/components/islands/CounterIsland.tsx`

**Component requirements:**

1. **Props interface:**
   - `end: number` - Target number to count up to
   - `suffix?: string` - Optional suffix (e.g., "+", "K")
   - `duration?: number` - Animation duration in seconds (default 2.5s)
   - `description: string` - Accessible label for screen readers

2. **Animation behavior:**
   - Use `useInView` hook from react-intersection-observer with `triggerOnce: true`
   - Trigger count-up animation when component enters viewport
   - Start from 0 and animate to `end` value over `duration` seconds
   - Use easing function for smooth deceleration (default easing in react-countup is fine)

3. **Accessibility (CRITICAL):**
   - Implement prefers-reduced-motion detection using `window.matchMedia('(prefers-reduced-motion: reduce)')`
   - If prefers-reduced-motion is true: Show final number immediately, no animation (duration = 0)
   - Add `aria-label` with description for screen readers
   - Ensure counter is semantic HTML (use `<span>` with proper role)

4. **TypeScript types:**
   - Define CounterIslandProps interface
   - Use proper React.FC typing
   - Export component as default

**Implementation pattern:**
```typescript
import { useInView } from 'react-intersection-observer';
import CountUp from 'react-countup';
import { useEffect, useState } from 'react';

interface CounterIslandProps {
  end: number;
  suffix?: string;
  duration?: number;
  description: string;
}

export default function CounterIsland({ end, suffix = '', duration = 2.5, description }: CounterIslandProps) {
  const { ref, inView } = useInView({ triggerOnce: true, threshold: 0.3 });
  const [prefersReducedMotion, setPrefersReducedMotion] = useState(false);

  useEffect(() => {
    const mediaQuery = window.matchMedia('(prefers-reduced-motion: reduce)');
    setPrefersReducedMotion(mediaQuery.matches);
  }, []);

  return (
    <span ref={ref} aria-label={description}>
      {inView && (
        <CountUp
          end={end}
          suffix={suffix}
          duration={prefersReducedMotion ? 0 : duration}
          separator=","
        />
      )}
    </span>
  );
}
```

**Why client:visible directive (to be used in Hero.astro):**
- Defers React hydration until component enters viewport
- Hero section is above fold, so CounterIsland loads almost immediately but after critical rendering path
- Reduces initial JavaScript bundle for faster LCP

**What to avoid:**
- DO NOT use client:load (forces immediate hydration, slows LCP)
- DO NOT animate layout properties (width, height)—only transform/opacity for GPU acceleration
- DO NOT skip prefers-reduced-motion check (accessibility requirement)
