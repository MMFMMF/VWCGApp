Modify ToolWrapper.tsx to add a PDF download button in the tool header.

**Changes:**

1. Add imports at top:


2. Inside the ToolWrapper component function (after the handleUpdate function), add PDF export handler:
   ```typescript
   const handleExportPDF = async () => {
     if (!tool.exportToPDF) return;

     try {
       const pdfSection = tool.exportToPDF(data);
       const blob = await generateSingleToolPDF({
         toolName: tool.metadata.name,
         pdfSection,
         generatedAt: new Date()
       });

       // Trigger download
       const url = URL.createObjectURL(blob);
       const a = document.createElement('a');
       a.href = url;
       a.download = getSingleToolReportFilename(tool.metadata.name, new Date());
       document.body.appendChild(a);
       a.click();
       document.body.removeChild(a);
       URL.revokeObjectURL(url);
     } catch (error) {
       console.error('PDF export failed:', error);
     }
   };
   ```

3. Determine if button should be shown:
   ```typescript
   const showPDFButton =
     tool.exportToPDF !== undefined &&
     tool.metadata.category !== 'synthesis' &&
     tool.metadata.id !== 'report-center' &&
     toolData?.data !== undefined &&
     Object.keys(data).length > 0;
   ```

4. Modify the header JSX. Replace the existing `<header className="mb-6">` section with:
   ```tsx
   <header className="mb-6 flex items-start justify-between">
     <div>
       <h1 className="text-2xl font-bold text-gray-900">{tool.metadata.name}</h1>
       <p className="mt-1 text-gray-600">{tool.metadata.description}</p>
       {tool.metadata.estimatedTime && (
         <span className="text-sm text-gray-500">

     {showPDFButton && (

         onClick={handleExportPDF}
   ```
