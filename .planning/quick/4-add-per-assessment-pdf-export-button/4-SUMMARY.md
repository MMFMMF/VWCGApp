# Quick Task 4: Add Per-Assessment PDF Export Button

**One-liner:** Individual assessment PDF download via ToolWrapper header button using jsPDF with VWCG branding, dimension tables, and key findings.

## What Was Done

### Task 1: Create single-tool PDF generator
**Commit:** c7a20bf
**File:** `src/lib/pdf/singleToolReport.ts` (208 lines)

Created a focused PDF generation function for individual assessment reports:
- `generateSingleToolPDF(config)` — produces a portrait A4 PDF with:
  - VWCG branding header (left) and generation date (right)
  - Tool name in 16pt bold
  - Summary/score section from PDFSection.summary
  - Dimension table from PDFSection.tables[0] with primary-color header row
  - Additional tables with lightGray header rows
  - Key findings bullet list from PDFSection.insights
  - Footer: "Generated by VWCGApp — vwcgapp.com" on all pages
  - Page numbers when multi-page
- `getSingleToolReportFilename(toolName, date)` — returns `VWCG-{SafeName}-{YYYY-MM-DD}.pdf`
- Reuses exact COLORS object from `generator.ts` for brand consistency
- Helper functions: `drawLine()` and `checkPageBreak()` matching generator.ts patterns

### Task 2: Add PDF download button to ToolWrapper
**Commit:** 2389655
**File:** `src/components/ToolWrapper.tsx` (63 insertions, 8 deletions)

Modified ToolWrapper to show a "Download PDF" button in the tool header:
- Added `useState` for loading state (`isGeneratingPDF`)
- `handleExportPDF` async handler: generates PDF blob, triggers browser download
- `showPDFButton` conditional logic:
  - Tool must have `exportToPDF` method
  - Category must not be `synthesis`
  - Tool ID must not be `report-center`
  - `toolData` must exist (user has entered data)
  - `data` must have keys (not empty default)
- Button styling: `bg-indigo-600 hover:bg-indigo-700` (Tailwind v4 compatible)
- Loading state: "Generating..." text with disabled state to prevent double-clicks
- Header layout changed to `flex items-start justify-between` for button placement
- Inline SVG download icon (Heroicons pattern, no new deps)

## Deviations from Plan
