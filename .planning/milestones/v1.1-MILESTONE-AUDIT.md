### URL Parameter Issue (LOW severity)

MiniAssessmentIsland CTA links to `/app?tool=ai-readiness`, but AssessmentApp doesn't read the `?tool=` query parameter. User lands at dashboard instead of AI Readiness tool directly.

**Impact:** Adds 1 extra click. localStorage bridge still works correctly — answers pre-populate when user navigates to AI Readiness manually.

**Recommendation:** Optional fix for v1.2 — add URL parameter handling to auto-navigate.
